# 角色档案 · 非人物视觉规格速查

> 用途：全 125 物种档案化时，**非人物角色**（兽/神兽/精灵/食物/器物/剑/数码等）按本文档填写 `petLifeStories.ts` 的 7 个视觉规格字段。人物/半人形角色按字段本义填写（见 `LifeStageStory` 接口注释）。
>
> 原则：**统一 7 字段，非人物做语义扩展**——生成脚本与提示词零改动，非人物角色提示词自动带出「体型/脸型五官/衣物细节/发型妆造/武器招式/功法表现/动作帧」。

## 一、7 字段非人物语义

| 字段 | 人物本义 | 非人物语义 | 关键信息 |
|------|---------|-----------|---------|
| `body` 体型 | 身高/头身比 | **体量/比例/姿态轮廓** | 头身比或体长、胖瘦、圆/长/扁、姿态 |
| `face` 脸型五官 | 眉/眼/鼻/下巴 | **神情五官（拟人化）** | 眼形、嘴形、腮、表情；食物/器物做拟人笑脸 |
| `actionSeq` 动作帧 | 人物动作关键帧 | **动作关键帧** | ①②③④连贯关键帧，SMIL 动图可直接拆 |
| `attireDetail` 衣物细节 | 衣物颜色纹理挂饰 | **皮表/纹样** | 毛色、鳞纹、花纹、材质纹理、绑绳/饰 |
| `hairStyle` 发型妆造 | 发型/束发/面饰 | **形态部件** | 角、尾、翼、鳍、鬃、触须、甲壳、耳 |
| `weaponAction` 武器招式 | 武器形制+招式 | **招牌攻击** | 爪/尾/角/火/光等攻击方式；无则留空 |
| `powerEffect` 功法表现 | 法力显化 | **能力显化** | 属性特效、光晕、气息、元素效果 |

## 二、各类别填写要点 + 示例

### 1. 神兽 / 瑞兽 / 龙（山海经·四象·烛龙/青龙/凤凰…）
- `body`：龙/兽身盘踞、昂首、粗壮等体态
- `face`：龙首/兽首，眼（日月/金瞳）、须、眉
- `attireDetail`：鳞甲颜色纹理（金鳞/青鳞）、腹甲、纹样
- `hairStyle`：角（珊瑚/鹿角）、须、背鳍、尾
- `weaponAction`：爪/尾/角/口衔火
- `powerEffect`：神通过显化（开目昼夜 / 龙职行云布雨 / 涅槃之火）
- 示例（烛龙六阶·开目为昼）：`body`'龙身盘踞约7头身长，粗壮如山，金光鳞甲'；`face`'龙首，双目日月分光，火红眉，长须垂垂'；`attireDetail`'金鳞细密泛光，腹甲乳白，鳞纹如水波'；`hairStyle`'珊瑚双角紫红，长须如鞭，背鳍如焰'；`weaponAction`'以爪/尾/烛火为攻'；`powerEffect`'双目睁为昼、闭为夜，口衔烛火照天'

### 2. 兽类（国宝·史前·猫科）
- `body`：体长/胖瘦/毛量（圆滚滚/高大）
- `face`：眼（圆/细/凶）、鼻、嘴、腮
- `attireDetail`：毛色主色调+花纹（条纹/斑点/斑纹）、腹部毛色
- `hairStyle`：耳、尾、鬃、獠牙、蹄爪
- `weaponAction`：爪/牙/冲撞/吼
- `powerEffect`：属性特效（雷电虎啸/冰封之力/山岳之力）
- 示例（华南虎六阶·山林归主）：`body`'约6头身，高大威猛，虎背熊腰'；`face`'虎脸，额间"王"字，虎目如电，虎须微动'；`attireDetail`'橙黄底毛，黑条纹如墨，腹白'；`hairStyle`'虎耳圆立，尾长有力，獠牙隐现'；`weaponAction`'虎扑/虎啸/利爪'；`powerEffect`'山林金光护体，虎啸震谷'

### 3. 元素精灵（宝可梦·魔法精灵）
- `body`：圆/长/球体比例
- `face`：大眼圆睁（萌系）、腮红、嘴
- `attireDetail`：主色+副色条纹/斑点，发光点
- `hairStyle`：耳、尾（闪电尾/绒尾）、翼、触角
- `weaponAction`：属性招式（十万伏特/火焰冲击/水枪）
- `powerEffect`：静电/火焰/水流环绕特效
- 示例（皮卡丘六阶·天雷滚滚）：`body`'约2头身，圆滚滚，黄毛短绒'；`face`'黑豆圆眼，红腮两点，小鼻，咧嘴笑'；`attireDetail`'通体金黄短毛，背部两道深棕纹，尾端闪电'；`hairStyle`'双耳尖长，尾如闪电，腮部电囊'；`weaponAction`'十万伏特'；`powerEffect`'静电环绕，电光噼啪'

### 4. 数码兽（数码宝贝）
- `body`：数码体比例
- `face`：数据眼、数码纹
- `attireDetail`：数码装甲纹理、数据纹路
- `hairStyle`：数据翼/装甲部件
- `weaponAction`：数码绝招
- `powerEffect`：数据粒子环绕、进化光

### 5. 植物 / 精灵（妙蛙种子·树精·妖精）
- `body`：植株/精灵比例
- `face`：拟人神情
- `attireDetail`：叶片/花瓣颜色纹理、藤蔓
- `hairStyle`：花苞、藤须、叶冠
- `weaponAction`：藤蔓/花粉/光合
- `powerEffect`：光合光点、花粉飘散

### 6. 食物（节日·粽子/汤圆/月饼/糖葫芦…）
- `body`：形状比例（三棱锥/圆/方/串）
- `face`：拟人笑脸（眉眼弯弯）
- `attireDetail`：外皮材质纹理（箬叶纹/糯米/糖衣）、绑绳、糖霜
- `hairStyle`：尖角、插旗、装饰、糖串棍
- `weaponAction`：特色招式（箬叶刃/粽香镇场/冰糖脆衣）
- `powerEffect`：香气/热气/寓意光效
- 示例（粽子六阶·忠魂浩然）：`body`'三棱锥形约3头身，棱角分明'；`face`'拟人小脸，眉眼弯弯，嘴角浩然'；`attireDetail`'箬叶青绿带纹，绑绳金红，米粒晶莹'；`hairStyle`'头顶箬叶尖角，身上缠绳'；`weaponAction`'箬叶刃/粽香镇场'；`powerEffect`'粽香弥漫，忠魂之气升腾'

### 7. 器物 / 法宝（器物·灯灵/葫芦/磬）
- `body`：器物形态比例
- `face`：器灵拟人神情（或留空）
- `attireDetail`：材质（青铜/白玉/木/瓷）、纹路、锈蚀或光泽
- `hairStyle`：器柄/流苏/悬饰
- `weaponAction`：器物作用（吞噬/释放/镇邪）
- `powerEffect`：器灵光、法阵、宝光

### 8. 剑客 / 剑意（剑意·七剑）
- `body`：剑形比例/拟人剑灵
- `face`：剑灵神情（锐利/温润）
- `attireDetail`：剑身纹路（云纹/冰纹）、剑格剑穗颜色
- `hairStyle`：剑穗、剑气飘发
- `weaponAction`：剑招（长虹贯日/冰魄惊鸿/青光掠影等）
- `powerEffect`：剑气/剑光/七剑合璧光

### 9. 星座圣斗士（星座·人形）——按人物字段本义，重点补
- `body`：圣衣形态
- `face`：人脸本义
- `attireDetail`：圣衣颜色+星座图腾纹
- `hairStyle`：星座盔冠
- `weaponAction`：必杀技（星光灭绝/天舞宝轮/庐山升龙霸）
- `powerEffect`：小宇宙光效

## 三、actionSeq 动作帧写法规范（为 SMIL 动图）
- 每阶段 4 帧（①②③④），每帧一个连贯动作：**起始 → 关键pose → 爆发 → 收势**
- 帧间动作连续，能直接作为 SVG `<animate>/<animateTransform>` 的关键值
- 避免同一角色各阶段动作帧雷同（每阶段换主动作）
- 示例：孙悟空六阶 `'①盘膝莲台 ②左掌结降魔印 ③右手拄金箍棒 ④金瞳微睁，佛光遍洒'`

## 四、原则
1. **非人物也要"每阶段独有"**：体型/部件/能力随阶段递进（一阶幼小无神通 → 六阶完全体），杜绝六阶"归真化淡"雷同
2. **皮表纹样颜色给色名**（金黄/青鳞/金红绑绳），供 AI 生图 / SVG 直接取用
3. **有 IP 的角色**（宝可梦/数码/圣斗士/七侠）按项目"版权直名、非商用致敬"政策直接用角色设定
4. **六阶按角色职责/独有特点定制**终局完全体，不落"云端神相+光环"静态套路（雷震子范例=奉旨·诛邪·护生）
