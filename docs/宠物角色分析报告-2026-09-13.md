## 三、角色卡文件夹是否多余？

**结论：内容冗余（100% 可再生成），但不建议直接删除——建议「取消 git 跟踪 + 按需再生成」。**

事实链：
1. `docs/角色卡/`（10 系列 126 个 md，2.6MB）是 `frontend-vue/scripts/generate-cards.mjs` 的**纯生成物**，唯一真相源是 `src/utils/` 下 8 个数据文件（petData / petDataExtended / petLifeStories / petProfiles / petTraits / stageEmoji / seriesStages / petArtStyles / stageAiPrompt）。
2. 源数据一改（如 9-13 当天 petData/petLifeStories 均有改动），卡就过期，且**无同步校验**——卡与源数据已经存在不一致风险（84 张卡的 undefined 即证据之一）。
3. 仓库 pack 仅 11.58 MiB，角色卡占约 1/5~1/4；每次源数据变更都会产生 126 文件级的大 diff。
4. 它的现实用途：AI 生图提示词取材、剧情文案人工审阅、`docs/待办清单.md` 的完成度凭证（126/126）。

推荐做法（二选一）：
- **方案 A（推荐）**：`.gitignore` 加入 `docs/角色卡/`，从 git 索引移除（保留本地），需要时 `node scripts/generate-cards.mjs` 一键再生成。文档里注明生成命令即可。
- **方案 B**：若把它当正式交付文案库保留跟踪，则必须修复下述生成器 bug，并加「卡与源数据哈希比对」的 CI/脚本校验防过期。

同族冗余提示：`docs/宠物AI生图提示词.md`、`frontend-vue/pet-prompts.csv`、`docs/角色档案·非人物视觉规格速查.md` 也是同源导出物，建议一并纳入「生成物不跟踪」策略。

## 四、宠物角色可优化点（按优先级）

### P1 · 生成器 bug：84 张卡「主题：undefined」
`generate-cards.mjs` L113 打印全局九维 `profile.theme`，而 `petProfiles.ts` 中 84 个物种的**全局级** theme 未填（stage 级已填齐）。
- 快修：L113 加 `|| '—'` 兜底（与 L75 的 `story?.theme || '—'` 一致），重新生成。
- 长修：给 84 个物种补全局 theme（可从其 transcendent 阶段 theme 提炼），或在审计脚本加「全局 theme 缺失」检测。

### P2 · 视觉规格缺失 65 处 / 29 物种
集中在：传统节日（食物系全部：粽子/汤圆/月饼/青团/年糕/馄饨等，face/attireDetail/hairStyle 几乎全缺）、宝可梦（伊布/利欧路）、国宝（丹顶鹤/东北虎等兽形类）、魔法奇幻部分。
- 食物/兽形「无服饰无发型」本身合理，但**缺省不应是空**——建议显式写「无（兽形/食物系）」，否则 AI 生图时风格漂移、构图不稳。
- 审计脚本已能检出（65 处），可按系列批量补齐后归零。

### P3 · 阶段 emoji 跨物种撞车
- L9 有 12 组重复（🔥：凤凰/小火龙→喷火龙/哪吒；🦅、🐉、🐆、⚡、❄️ 各 2~3 物种）。
- L12 🌟 被 14 个物种共用（12 星座 + 凤凰 + 杨戬）——星座系列统一符号可接受，建议在系列常量里显式声明「系列统一道果 emoji」而非靠重复。
- L1 全员 🥚 属设计约定，跳过。
- 影响：大屏/图鉴列表按 emoji 区分度下降。可为同组物种改用近义 emoji（🔥→🔥/🌋/☀️）。

### P4 · 运行时体积
- `PokedexPage` chunk ≈ **992KB**（内含 petLifeStories 1.16MB 源码压缩后主体），是全站最大 chunk；LeaderboardPage 424KB、StudentsPage 342KB 也偏大。
- 优化方向：① 图鉴按**系列**动态 import（10 个系列分片，首屏只载 1~2 个系列）；② 或把六阶段长文案迁到后端接口按需拉取，前端只留 id→文案 的惰性映射；③ petData 与 petDataExtended（105KB+82KB）可合并为一个索引化 JSON。

### P5 · 数据结构长期维护
叙事/档案/特质分散在 5 个 40KB~1.1MB 的巨型 TS 对象文件，靠脚本审计兜底。若后续宠物还要扩（系列/等级），建议迁移到「每系列一个 JSON + 顶层索引」，生成卡/提示词脚本直接消费 JSON，TS 只留类型与查询函数。

### P6 · 两处小数据修正
- 等级名称重复：「闪电拳雏形」同时用于狮子座·艾奥里亚 L6 与射手座·艾俄洛斯 L5，改其一。
- 虹猫七侠 7 人共享传说特质「七剑合璧」属剧情设定，可保留，但建议每人在共享技能下加一行差异描述。
