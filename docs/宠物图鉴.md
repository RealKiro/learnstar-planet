## 2. 数据文件职责（key 约定）

| 文件 | 职责 | 主键 |
|------|------|------|
| `utils/petData.ts` | 系列定义 `PET_SERIES`、物种 `levels`（12 级 name/description/stage）、`SPECIES_EMOJI`、`SERIES_SCENES`、查询函数 | species `id` |
| `utils/petDataExtended.ts` | `EXTRA_SPECIES` 补物种 + `EXTRA_SERIES`（festival/qixia），运行时合并进 `PET_SERIES` | species `id` |
| `utils/petArtParts.ts` | `PET_ART` 每物种 `{body, main, variant, parts, stageVariants?, stageMain?}`、`computePetArt` | species `id` |
| `utils/petProfiles.ts` | 角色档案 `PET_PROFILES`：`{form, habit}` | species `id` |
| `utils/petTraits.ts` | 特质 `PET_TRAITS`：`T(性格[5], 招式[5])` | species `id` |
| `utils/petHandbookData.ts` | `PET_POEMS`(6段诗文) + `PET_EVO_LINES`(6段台词) | **species `name`**（注意：与上面不同！） |

> ⚠️ **重要约定**：`PET_POEMS`/`PET_EVO_LINES` 用 **species.name 字符串**做 key（如 `'白羊座·穆'`）。改物种 `name` 时必须同步改这两张表的 key，否则诗文/台词查不到（运行时 `getPoems(species.name)`）。

### 物种数据结构
```ts
interface PetSpecies { id: string; name: string; seriesId: string; levels: PetLevel[] }
interface PetLevel { level: number; name: string; description: string; stage: 'egg'|'baby'|'growing'|'mature'|'legendary'; requiredScore: number }
interface PetSeries { id: string; name: string; emoji: string; species: PetSpecies[] }
```

## 4. 进化体系

### 4.1 12 级 → 5 阶段
| 阶段 | 等级 | 视觉特征（`computePetArt`） |
|------|------|---------------------------|
| egg | 1-2 | 体型 0.9、微光、闭眼、无部件 |
| baby | 3-5 | 体型 1.0、无光、大眼、腮红，只保留基础 tail |
| growing | 6-8 | 体型 1.12、中光，开放 horns |
| mature | 9-10 | 体型 1.26、强光，开放 wings/fin |
| legendary | 11-12 | 体型 1.4、满光，开放 halo/crown |

### 4.2 阶段差异化机制
1. **程序化基线**（全物种生效）：`computePetArt` 按阶段对 `main` 色做明暗（egg +0.45 / baby +0.28 / growing +0.05 / mature -0.18 / legendary +0.12），并逐阶段开放部件（§4.1）。
2. **重点角色手调**：`PetArtConfig.stageMain`（各阶段配色覆盖）+ `stageVariants`（各阶段剪影变体，PetSprite 支持 60+ variant 分支）。已手调：宝可梦御三家、虹猫、蓝兔、黑心虎、黑小虎。

### 4.3 未来演进方向（待完善）
- **分支进化**：同一物种在特定等级按条件（积分/道具/班级主题）走不同终极形态 —— 数据结构需扩展 `levels` 支持条件分支。
- **跨物种进化**：如"伊布"类可进化成多物种 —— 需在 species 加 `evolvesTo?: string[]` 与条件。
- **剧情推演**：对 IP 系列（七侠/圣斗士/数码宝贝）按原作剧情推进（如虹猫→长虹贯日、穆→星光灭绝）—— 现 12 级已按此设计，可继续细化各阶段情节。

## 5. 角色档案数据层（现状 + 深化方向）

每只宠物目前的"档案"由 4 张表构成：

| 数据 | 字段/结构 | 文件 |
|------|----------|------|
| 形态/习性 | `form`（外形容） + `habit`（习性） | petProfiles.ts |
| 诗文 | 6 段七言绝句（每阶段 1 段，`poemToLines` 两行展示） | petHandbookData.ts `PET_POEMS` |
| 进化台词 | 6 段 "..." 台词（每阶段 1 段） | petHandbookData.ts `PET_EVO_LINES` |
| 特质 | `T(性格[5], 招式[5])`（随阶段取对应项） | petTraits.ts |

### 深化方向建议
1. **背景故事**：新增 `PET_BACKSTORIES` 表（`speciesId → 一段世界观/身世`），在图鉴"角色档案"区展示，可配合 AI 生成。
2. **专属称呼/口头禅**：`nickname`/`catchphrase` 字段，宠物命名时使用。
3. **与同学互动**：`likes/dislikes`（喜欢的积分类别/活动），用于积分理由推荐与宠物反应。
4. **图鉴稀有度/标签**：`rarity`（常见/稀有/传说）、`tags`（可编程/治愈系…），用于图鉴筛选与收藏。

## 6. SVG 渲染机制（当前）

- `PetSprite`（2200+ 行）内联 SVG：输入 `speciesId + level + mood + animate`，输出 viewBox 200×200 的宠物图。
- `body` 模板（8 类：dragon/quadruped/bird/aquatic/mecha/spirit/food/humanoid）+ `variant` 分支（60+ 种：tiger/lizard/cat/knight/phoenix…）决定外形。
- 颜色：`main` → `shade()` 推导 accent/dark/light 色阶；阶段差异靠 scale/glow/部件/配色（§4）。

## 7. AI 绘制图片替代 SVG（数据契约与改造方案）

### 7.1 目标
用 AI（如 Midjourney/DALL·E/SD）生成**每只宠物每个阶段的角色图**（PNG/WebP），替换程序化 SVG，提升角色辨识度与美术质量。共需 **123 物种 × 5 阶段 ≈ 615 张**（egg/baby/growing/mature/legendary 各 1 张，等级共享阶段图）。

### 7.2 资源目录与命名规范
```
public/pets/{seriesId}/{speciesId}-{stage}.webp
# 例：
public/pets/constellation/aries-egg.webp
public/pets/constellation/aries-legendary.webp
public/pets/qixia/hongmao-legendary.webp
```

### 7.3 前端加载改造（PetSprite 图片优先、SVG 回退）
```ts
// 新工具函数：utils/petImage.ts
export function getPetImageUrl(speciesId: string, stage: PetStage): string | null {
  // 仅当该物种已生成图片资源时返回 URL（用一份 MANIFEST 记录已生成的 id）
  const MANIFEST: string[] = [...] // 已生成的 speciesId（可程序生成）
  return MANIFEST.includes(speciesId)
    ? `${import.meta.env.BASE_URL}pets/${seriesIdOf(speciesId)}/${speciesId}-${stage}.webp`
    : null
}
```
`PetSprite.vue` 改造：渲染时先查 `getPetImageUrl(speciesId, stage)`，命中则 `<img>` 占位（保留现有尺寸容器与动画类），未命中回退当前 SVG 逻辑。**建议不破坏现有 SVG 路径**，用 `v-if="imgUrl"` 分支。

### 7.4 AI 提示词模板
每张图需要一段提示词。可从现有数据自动拼装（无需手写 615 条）：
```
[角色名]：{species.name} 的 {stage} 阶段。
外形：{species.levels 对应阶段的首个 level.name + description}。
系列：{series.name}（{SERIES_SCENES[seriesId].scene}）。
风格：儿童友好的 2.5D 卡通渲染，柔和渐变背景，居中全身像，正面 3/4 视角，无文字。
主色：{PET_ART[speciesId].main}。
```
可先生成"重点角色"（虹猫蓝兔、12 圣斗士、宝可梦御三家、黑小虎）615 张中的首批 ~50 张验收风格，再全量铺开。

### 7.5 需要配套的清单
- `docs/pet-image-manifest.md`：已生成图片的 speciesId 登记（PetSprite 据此回退）。
- 生成脚本（可选）：从 petData 读取物种，批量产出提示词 CSV。
- 验收标准：风格统一、与阶段特征一致（幼年小/可爱、传说带光环/圣衣）、透明或统一背景。
