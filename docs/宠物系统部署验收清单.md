## 一、切换规则最终版（已厘清）

### 1.1 规则总表（最终版）

| 规则 | 实现 | 状态 |
|------|------|------|
| 同一时间激活 1 只 | `pets` 表一行/学生（student_id unique） | ✅ |
| **类别限制（硬规则）** | **只能领养本班当前类别**（`class.settings.pet_series`）的宠物，**不能跨类别领养**；未设置类别时不限制（422 "只能领养当前类别…"） | ✅ 本轮实现 |
| 同物种守卫 | 换到当前宠物 → 422，不扣分不重置 | ✅ |
| **更换成本（积分，等级越高越贵）** | `Pet::switchCost(level) = 5 × level`（Lv.1=5 … Lv.12=60），从 `total_score` 扣除，不足则 400 | ✅ 本轮实现 |
| **免费自选机会** | 整班切换系列后每人获**一次免费更换**（`pet_free_pick` 缓存，**3 天内有效**），限当前类别，使用即失效；3 天内未用则过期，之后需花积分 | ✅ 本轮实现 |
| 进度保留 | 切走时旧物种等级/经验/心情存入 `pet_collections`；切回时完整恢复 | ✅ |
| 首次创建 | 无宠物时创建 Lv.1 宠物 + 收入收藏（同样限当前类别） | ✅ |
| **整班切换系列（教室端）** | `POST /display/switch-series`：**只要有一人积分<20 则整班拒绝**；通过后每人扣 20 分，并各发一次免费自选机会 | ✅ 本轮实现 |
| **整班切换系列（教师端）** | `POST /teacher/class/switch-series`：不扣分（管理操作），同样发免费自选机会 | ✅ 本轮实现 |
| 单生切换（教室端） | `POST /display/pets/switch`：限当前类别；免费自选则免费，否则按等级扣积分 | ✅ 本轮实现 |
| 单生切换（教师端） | `POST /teacher/pets/{id}/switch`：限当前类别；免费自选则免费，否则按等级扣积分 | ✅ 本轮实现 |
| 图鉴查询 | `GET /api/v1/teacher/pets/{studentId}/collection`（含 `class_series` 当前类别） | ✅ |

### 1.2 关键决策点（实现取舍，验收时确认符合预期）

1. **成本从 `total_score`（积分）扣除，按等级线性定价**：`5 × level`，等级越高越贵，符合"必须花积分兑换"。扣分后宠物等级**不立即重算**（避免扣分连坐降级），下次加分时再由 `syncLevelWithScore()` 同步。
2. **类别由 `class.settings.pet_series` 决定**：整班切换系列后锁定类别，所有单生切换/首次创建都在该类别内；未设置时不限制（初始自由选）。
3. **整班切换＝扣分 + 发免费自选**：教室端一人不足 20 分整班拒绝；通过后每人扣 20 分并发一次免费自选。宠物不自动变更——由学生各自用免费机会或积分选择。
4. **已移除的机制**（按最新需求收敛）：7 天冷却、图鉴槽位门控、首次免费、随机分配。若需恢复可基于 `pets.last_switched_at` / `unlockSlotsForScore` 再加。
5. **阶段映射统一**：Lv.1-2 卵生 / 3-5 幼年 / 6-8 成长 / 9-10 成熟 / 11-12 传说，前后端一致。
6. **后端仅保留物种 id 级字典**：`Pet::speciesPoolForSeries()` 只存每系列 12 个物种 id（类别限制用），不存等级/描述；`petData.ts` 仍是唯一完整事实来源。

### 1.3 未实现/待迭代（明确边界）

- **家长端查看收藏/更换** 未做（家长目前只能看激活宠物）。
- **成就/活动解锁类别** 未做（目前整班切换由教师/教室触发）。
- 免费自选机会 **3 天窗口**：整班切换后 3 天内可用一次（免费、限当前类别），过期作废；之后切换一律花积分。

## 二、部署步骤

### 2.1 后端

```bash
cd backend
composer install          # 新增文件无新第三方依赖（PetCollection 为模型）
php artisan migrate       # 关键：执行 000005_(宠物) / 000006_(清家长) / 000007_(汇率1:1+奖励惩罚) 迁移
php artisan config:cache  # 注意：config 直调 env() 的 11 处是已知隐患，见 CLAUDE.md
php artisan route:cache
php artisan optimize      # 或按项目既有流程
```

> ⚠️ 若之前跑过 `config:cache`，本次改动只涉及路由/模型/控制器，`config:cache` 需重新执行。
> ⚠️ 迁移是**一次性不可逆增强**（加列 + 回填 + 建表），建议先在测试库跑通再上生产。

### 2.2 前端

```bash
cd frontend-vue
npm install
npm run typecheck          # 已通过（vue-tsc --noEmit）
npm run build              # 已通过（vite）
# 部署产物：npm run build:deploy（输出到 ../backend/public）
```

### 2.3 数据校验（迁移后）

```sql
-- 1) pets.species 是否回填
SELECT type, species, COUNT(*) FROM pets GROUP BY type, species;
-- 期望：species 无 NULL（或仅少量未映射回退 'zhulong'）

-- 2) 收藏表已建
SHOW TABLES LIKE 'pet_collections';
SELECT COUNT(*) FROM pet_collections;

-- 3) 等级上限校验（旧 50 级表已改为 12 级）
SELECT MAX(level) FROM pets;   -- 期望 ≤ 12
```
