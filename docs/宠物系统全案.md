### 1.2 进化体系概述

- **每物种 12 级**（Lv.1 蛋 → Lv.12 终极形态），统一累计积分门槛 `S = [0,15,35,60,90,125,165,210,260,315,375,450]`（后端 `syncLevelWithScore()` 为前置补 0 的 `[0,0,15,…]`，两端同表）。
- **6 阶段**：`egg`(Lv.1-2) / `baby`(Lv.3-4) / `growing`(Lv.5-6) / `mature`(Lv.7-8) / `legendary`(Lv.9-10) / `transcendent`(Lv.11-12，归真)，前后端经 `getLevelStage()` / `currentStage()` 一致映射。
- **渲染**：程序化 SVG（`PetSprite` + `computePetArt`），已具备阶段差异化（`stageMain` / `stageVariants`）；AI 逐阶段图片为可选替代方案（见第六章）。

### 1.3 旗舰系列设计要点

**星座守护 · 圣衣进化模板（12 级）**
Lv.1 小宇宙之种 → Lv.2-3 圣斗士候补 → Lv.4-5 青铜圣衣 → Lv.6 白银圣衣 → Lv.7-8 黄金圣衣初现 → Lv.9-10 黄金圣斗士（完全觉醒）→ Lv.11 第七感（燃烧小宇宙）→ Lv.12 神圣衣（超越女神之光）。
SVG 上圣衣是"穿戴部件层"，随等级点亮肩甲 / 胸甲 / 披风，是逐级视觉变化最易出彩的系列。联动落地：① 进化名沿用"青铜 / 白银 / 黄金 / 神圣衣"；② 获得黄金圣衣时触发"黄金十二宫试炼"提示；③ 全班 ≥6 人激活星座系列，解锁"燃烧小宇宙"班级加成动画。

**虹猫蓝兔七侠传 · 剑法进化模板（12 级）**
Lv.1 剑意种子 → Lv.2-3 习剑入门 → Lv.4-5 剑招小成 → Lv.6 剑气成形 → Lv.7-8 名剑加身 → Lv.9-10 剑道大师 → Lv.11 剑气纵横 → Lv.12 七剑合璧（或独门绝招：长虹贯日 / 冰魄惊鸿…）。
联动玩法：① 集齐 7 位持剑侠客触发"七剑合璧"班级全屏动画 + 全员加成；② 黑心虎可走"暗系觉醒"分支，班级活动显示"反派气质"标签，可随时悔悟切回。⚠️ 本项目非商用、自托管、免费开源，以"致敬 / 同人"方式使用角色名；若未来商用可一键替换为原创名（数据模型不变）。

**传统节日 · 诗词显化**
每个物种绑定一位诗人 / 典故，进化台词与阶段名从诗词中化用；图鉴展示"出处诗句"，语文课可直接当教具。SVG 每物种配一件"文房元素"（毛笔 / 书卷 / 砚台 / 印章），传说级显化诗句文字。

### 1.4 数据文件职责（key 约定）

| 文件 | 职责 | 主键 |
|------|------|------|
| `utils/petData.ts` | 系列定义 `PET_SERIES`（7 基础系列）、物种 `levels`（12 级 name/description/stage）、`SPECIES_EMOJI`、`SERIES_SCENES`、查询函数 | species `id` |
| `utils/petDataExtended.ts` | `EXTRA_SPECIES` 补物种 + `EXTRA_SERIES`（festival/qixia/dongfang），运行时合并进 `PET_SERIES` | species `id` |
| `utils/petArtParts.ts` | `PET_ART` 每物种 `{body, main, variant, parts, stageVariants?, stageMain?}`、`computePetArt` | species `id` |
| `utils/petProfiles.ts` | 角色档案 `PET_PROFILES`：`{form, habit}` | species `id` |
| `utils/petTraits.ts` | 特质 `PET_TRAITS`：`T(性格[5], 招式[5])` | species `id` |
| `utils/petHandbookData.ts` | `PET_POEMS`(6 段诗文) + `PET_EVO_LINES`(6 段台词) | **species `name`**（注意：与上面不同！） |

> ⚠️ **重要约定**：`PET_POEMS` / `PET_EVO_LINES` 用 **species.name 字符串**做 key（如 `'白羊座·穆'`）。改物种 `name` 时必须同步改这两张表的 key，否则诗文 / 台词查不到（运行时 `getPoems(species.name)`）。

### 1.5 物种数据结构

```ts
interface PetSpecies { id: string; name: string; seriesId: string; levels: PetLevel[] }
interface PetLevel { level: number; name: string; description: string; stage: 'egg'|'baby'|'growing'|'mature'|'legendary'; requiredScore: number }
interface PetSeries { id: string; name: string; emoji: string; species: PetSpecies[] }
```

## 三、进化体系

### 3.1 12 级 → 6 阶段

| 阶段 | 等级 | 性格基调 | 视觉特征（`computePetArt`） |
|------|------|----------|---------------------------|
| 卵生 egg | Lv.1-2 | 期待、懵懂、脆弱 | 体型 0.9、微光、闭眼、无部件 |
| 幼年 baby | Lv.3-4 | 好奇、莽撞、粘人 | 体型 1.0、无光、大眼、腮红，只保留基础 tail |
| 成长 growing | Lv.5-6 | 好胜、顽皮、初具种族特征 | 体型 1.12、中光，开放 horns |
| 成熟 mature | Lv.7-8 | 沉稳、守护、气场 | 体型 1.26、强光，开放 wings/fin |
| 传说 legendary | Lv.9-10 | 神性、悲悯、超然 | 体型 1.4、满光，开放 halo/crown |
| 归真 transcendent | Lv.11-12 | 返璞归真、道心圆满 | 体型 1.55、满光，全部件 |

### 3.2 阶段差异化机制

1. **程序化基线**（全物种生效）：`computePetArt` 按阶段对 `main` 色做明暗（egg +0.45 / baby +0.28 / growing +0.05 / mature -0.18 / legendary +0.12），并逐阶段开放部件（§3.1）。
2. **重点角色手调**：`PetArtConfig.stageMain`（各阶段配色覆盖）+ `stageVariants`（各阶段剪影变体，PetSprite 支持 60+ variant 分支）。已手调：宝可梦御三家、虹猫、蓝兔、黑心虎、黑小虎。

### 3.3 三种路线类型

1. **线性进化（Linear）**：一条主线 12 级，前后有清晰的体型 / 性格成长弧线，适合大多数物种（默认）。
2. **分支进化（Branch）**：到达指定等级（如 Lv.6）时按**养成行为**选择方向，此后 6 级走不同形态与性格（参考"伊布"、双子座"光 / 影"、黑心虎"光 / 暗"）。
3. **融合进化（Fusion）**：两条分支在 Lv.9+ 融合为"究极形态"（如 火×风=风暴龙），需同时满足两条分支的成就。

**分支 / 融合条件（可量化的养成行为）**：

| 条件类型 | 示例 |
|----------|------|
| 行为倾向 | 投喂次数 / 加分方向（学习币 vs 读书币） |
| 成就解锁 | 连续连击天数、考勤全勤、作业提交率 |
| 属性达标 | 心情值、专注值、某科目积分 |
| 时间条件 | 只在特定节日 / 季节可进化 |

> 落地建议：第一版**只做线性**，把分支 / 融合作为数据模型预留（`route` / `branches` 字段），玩法后续迭代再启用。

### 3.4 未来演进方向（待完善）

- **分支进化**：同一物种在特定等级按条件（积分 / 道具 / 班级主题）走不同终极形态 —— 数据结构需扩展 `levels` 支持条件分支。
- **跨物种进化**：如"伊布"类可进化成多物种 —— 需在 species 加 `evolvesTo?: string[]` 与条件。
- **剧情推演**：对 IP 系列（七侠 / 圣斗士 / 数码宝贝）按原作剧情推进（如虹猫→长虹贯日、穆→星光灭绝）—— 现 12 级已按此设计，可继续细化各阶段情节。

## 四、切换规则

> 核心目标：让"图鉴收集 + 养成选择"成为长期动力，同时限制反复横跳。以下为**最新最终版规则**（已收敛：移除 7 天冷却、图鉴槽位门控、首次免费、随机分配）。

### 4.1 规则总表（最终版）

| 规则 | 实现 | 状态 |
|------|------|------|
| 同一时间激活 1 只 | `pets` 表一行 / 学生（student_id unique） | ✅ |
| **类别限制（硬规则）** | 只能领养本班当前类别（`class.settings.pet_series`）的宠物，**不能跨类别领养**；未设置类别时不限制（422 "只能领养当前类别…"） | ✅ |
| 同物种守卫 | 换到当前宠物 → 422，不扣分不重置 | ✅ |
| **更换成本（积分，等级越高越贵）** | `Pet::switchCost(level) = 5 × level`（Lv.1=5 … Lv.12=60），从 `total_score` 扣除，不足则 400 | ✅ |
| **免费自选机会** | 整班切换系列后每人获**一次免费更换**（`pet_free_pick` 缓存，**3 天内有效**），限当前类别，使用即失效；过期后需花积分 | ✅ |
| 进度保留 | 切走时旧物种等级 / 经验 / 心情存入 `pet_collections`；切回时完整恢复 | ✅ |
| 首次创建 | 无宠物时创建 Lv.1 宠物 + 收入收藏（同样限当前类别） | ✅ |

| 图鉴查询 | `GET /api/v1/teacher/pets/{studentId}/collection`（含 `class_series` 当前类别） | ✅ |

### 4.2 关键决策点

1. **成本从 `total_score`（积分）扣除，按等级线性定价** `5 × level`；扣分后宠物等级**不立即重算**（避免扣分连坐降级），下次加分时由 `syncLevelWithScore()` 同步。
2. **类别由 `class.settings.pet_series` 决定**：整班切换系列后锁定类别，所有单生切换 / 首次创建都在该类别内；未设置时不限制（初始自由选）。
3. **整班切换 = 扣分 + 发免费自选**：教室端一人不足 20 分整班拒绝；通过后每人扣 20 分并发一次免费自选。宠物不自动变更——由学生各自用免费机会或积分选择。
4. **进度保留采用方案 A（全保留）**：切走的旧物种等级 / 经验 / 心情永久保存在图鉴，切回时完整恢复，无挫败感。
5. **已移除机制**：7 天冷却、图鉴槽位门控、首次免费、随机分配。若需恢复可基于 `pets.last_switched_at` / `unlockSlotsForScore` 再加。

### 4.3 解锁规则

- **初始 1 只**：注册 / 建档后自动获得第 1 只（随机神话物种 Lv.1）。
- **图鉴收藏**：其余物种通过整班切换类别或单生切换解锁；`pet_collections` 记录每个物种的最高养成进度。图鉴槽位（`unlockSlotsForScore`，每 100 积分 +1，初始 1）**仅作展示，切换不再门控**。

### 4.4 图鉴 / 宿舍系统

- 「宠物图鉴」视图（`PetHandbook.vue` + `PetCollection.vue`）：展示已解锁物种数 / 总数（131）、每物种已收集的最高形态（点亮图鉴卡片）、未解锁物种的解锁条件提示。
- 前端数据流：`pet_collections` 表（收藏 / 各物种进度）+ `pets`（当前激活宠物）；教师端 `PetsPage` 展示全班激活宠物 + 每名学生图鉴进度。

### 4.5 未实现 / 待迭代（明确边界）

- **家长端查看收藏 / 更换** 未做（家长目前只能看激活宠物）。
- **成就 / 活动解锁类别** 未做（目前整班切换由教师 / 教室触发）。
- 免费自选机会为 **3 天窗口**：整班切换后 3 天内可用一次（免费、限当前类别），过期作废；之后切换一律花积分。

## 六、SVG 绘制体系 与 AI 绘图替代方案

### 6.1 SVG 目标与架构

> 目标：每个等级都有**专属 SVG 形象**，生动有趣、逐级渐变、可动画、可离线。用"组件 + 数据驱动"而非 131×12 张死图。

```
PetSprite.vue（2200+ 行内联 SVG）
 ├─ 输入： speciesId, level, mood, animate, size
 ├─ 解析： getLevelArt(speciesId, level) → PetLevel['art']
 └─ 输出： viewBox 200×200 内联 <svg> 分层渲染
      ├─ defs（渐变 / 滤镜 / 发光）
      ├─ 身体部件（<g>）： 由 art.body 指定部件模板
      ├─ 阶段修饰： 蛋壳 / 幼体 Q 版 / 成体部件 / 圣衣 / 光环
      ├─ 特效层： 火焰 / 雷电 / 星尘 / 数据流（SMIL 动画）
      └─ 表情层： 眼睛 / 嘴随 mood 切换
```

- **部件库**：`petArtParts.ts` 提供基础几何部件（圆身 / 椭圆身 / 三角头 / 角 / 翼 / 尾 / 光环 / 圣衣肩甲…），按 `body` 键组合；`body` 模板 8 类（dragon / quadruped / bird / aquatic / mecha / spirit / food / humanoid）+ `variant` 分支 60+ 种（tiger / lizard / cat / knight / phoenix…）决定外形。
- **颜色**：`main` → `shade()` 推导 accent / dark / light 色阶；阶段差异靠 scale / glow / 部件 / 配色。
- **逐级变化参数**：`art.scale`（体型）、`art.color`（主色随等级加深）、`art.glow`（发光强度）、`art.fx`（特效数量）——同一部件模板 + 参数渐变 = 12 个不同观感形态，成本远低于逐级手绘。
- **关键形态跃迁**：Lv.2 破壳（蛋壳裂开）、Lv.6 部件成形（角 / 翼 / 圣衣出现）、Lv.9 完全体、Lv.12 究极（光环 + 全屏特效）。这 4 个跃迁点做**专属装饰层**，保证"进化瞬间"有视觉冲击。

### 6.2 每阶段视觉语言

| 阶段 | SVG 表达 |
|------|----------|
| 卵生 | 椭圆蛋 + 裂纹 / 脉动光晕 + 内影轮廓；动画：轻微呼吸起伏 |
| 幼年 | 大头小身 Q 版、圆眼大而亮、四肢短、腮红；动画：眨眼 / 摇晃 |
| 成长 | 体型拉长、主色饱和度上升、出现种族部件（角 / 鳍 / 甲）；动画：更有力 |
| 成熟 | 部件齐全、配色对比增强、眼神锐利；动画：尾巴摇动 / 振翅 |
| 传说 | 半透明 + 粒子特效 + 旋转光环 + 元素环绕；动画：流光、粒子飘散 |

### 6.3 实施阶段

| 阶段 | 内容 | 工作量 |
|------|------|--------|
| A · 框架 | `PetSprite.vue` + 部件库 + 参数体系 + 3 个旗舰物种（烛龙 / 皮卡丘 / 白羊座）打通 | 中 |
| B · 全量 | 125 物种 × 12 级 art 参数（优先"部件复用 + 参数渐变"） | 大 |
| C · 特效 | 每系列专属特效（神话云火 / 机甲数据流 / 星座星尘…）+ 进化瞬间全屏动画 | 中 |
| D · 整合 | 替换 `PetDisplay.vue` / `PetsPage.vue` / `PetHandbook.vue` / `PetEvolutionTree.vue` 中的 emoji | 小 |

> **SVG 绘制守则**：① 一个物种一档主色，等级越高色越纯越亮；② 部件变化遵循"从无到有、从小到大、从单一到华丽"；③ 每级至少有一个可感知变化（体型 / 颜色 / 部件 / 光效）；④ 眼睛与嘴跟随心情，保证"生动"。

### 6.4 AI 绘制图片替代 SVG（数据契约）

**目标**：用 AI（Midjourney / DALL·E / SD）生成每只宠物每个阶段的角色图（PNG/WebP），替换程序化 SVG，提升角色辨识度与美术质量。共需 **125 物种 × 5 阶段 ≈ 625 张**（egg/baby/growing/mature/legendary 各 1 张，等级共享阶段图）。

**资源目录与命名规范**

```
public/pets/{seriesId}/{speciesId}-{stage}.webp
# 例：
public/pets/constellation/aries-egg.webp
public/pets/constellation/aries-legendary.webp
public/pets/qixia/hongmao-legendary.webp
```

**前端加载改造（PetSprite 图片优先、SVG 回退）**

```ts
// 新工具函数：utils/petImage.ts
export function getPetImageUrl(speciesId: string, stage: PetStage): string | null {
  // 仅当该物种已生成图片资源时返回 URL（用一份 MANIFEST 记录已生成的 id）
  const MANIFEST: string[] = [...] // 已生成的 speciesId（可程序生成）
  return MANIFEST.includes(speciesId)
    ? `${import.meta.env.BASE_URL}pets/${seriesIdOf(speciesId)}/${speciesId}-${stage}.webp`
    : null
}
```

`PetSprite.vue` 改造：渲染时先查 `getPetImageUrl(speciesId, stage)`，命中则 `<img>` 占位（保留现有尺寸容器与动画类），未命中回退当前 SVG 逻辑。**建议不破坏现有 SVG 路径**，用 `v-if="imgUrl"` 分支。

**AI 提示词模板（可从现有数据自动拼装，无需手写 605 条）**

```
[角色名]：{species.name} 的 {stage} 阶段。
外形：{species.levels 对应阶段的首个 level.name + description}。
系列：{series.name}（{SERIES_SCENES[seriesId].scene}）。
风格：儿童友好的 2.5D 卡通渲染，柔和渐变背景，居中全身像，正面 3/4 视角，无文字。
主色：{PET_ART[speciesId].main}。
```

可先生成"重点角色"（虹猫蓝兔、12 圣斗士、宝可梦御三家、黑小虎）625 张中的首批 ~50 张验收风格，再全量铺开。

**需要配套的清单**

- `docs/pet-image-manifest.md`：已生成图片的 speciesId 登记（PetSprite 据此回退）。
- 生成脚本（可选）：从 petData 读取物种，批量产出提示词 CSV。
- 验收标准：风格统一、与阶段特征一致（幼年小 / 可爱、传说带光环 / 圣衣）、透明或统一背景。

| 5 | 迁移回填漏带前缀 type（`pokemon_qilin`）→ 静默变烛龙 | 生成 15 前缀变体覆盖 |
| 6 | 迁移 `down()` 漏删 `last_switched_at` | 补 `dropColumn` |
| 7 | `currentStage()` 不再返回 `exp_max` → 大屏进度条恒 100 | 补 `exp_max` |
| 8 | `classroomSwitchPet` 不给目标物种写收藏 → 图鉴显示"未拥有"、进度丢失 | 补目标物种 `updateOrCreate(is_active=true)` |

**待决策 / 建议（非阻塞）**

- **等级双驱动冲突**：`switchPet` 从收藏恢复等级，但 `syncLevelWithScore()` 以总积分为准，下次加分会把等级重算回积分档。需明确"等级=积分驱动"还是"每物种独立进度"。
- **成本可被"切到新物种=重置 Lv.1"绕过**：Lv.12 先花 60 切到新物种 Lv.1，之后每切一次只花 5 分。若想堵住，可改为"成本=目标物种收藏等级或当前等级取大"。
- **收敛建议**：类别限制（3 份）、免费自选缓存键（6 处）、收藏快照（5 处）应下沉为 `Pet` / `PetCollection` 方法或 `PetSwitchService`。
- **PHPStan Level 5**：`$class->settings['pet_series']` 为 mixed，传给 `speciesPoolForSeries(string)` 会报类型错，需 `(string)` 强转。
- **API 约定**：新增 `petCollection` / `switchPet` 响应只含 `data`，按 CLAUDE.md 应含 `message/meta`。
- **死代码**：`Pet::evolutionStagesForType()` 无引用；`unlockSlotsForScore()` 已不门控；`last_switched_at` 只写不读（若不再需要冷却可删列）。
